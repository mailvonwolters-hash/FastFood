# FastFood – Smart Delivery & Route Manager

Ein stressfreies, erschütterungssicheres Auslieferungssystem für Speisen auf Rädern.

## Kern-Features & Workflow
- **Morgen-Packzettel:** Automatische Mengenauswertung für die Küche & Farbkassetten (Grün/Rot/Blau).
- **Fresspanzer-Proof Driver UI:** 4 riesige Trefferzonen zur blinden Leerguterfassung (+1 / 0 / Alu / Notiz).
- **Ausfallsicherheit:** Automatische Sperre vor dem nächsten Kunden, bis Leergut erfasst ist.
- **Feierabend-Automatisierung:** Sofortige Kochmengenberechnung für den Folgetag.

## Branch-Struktur
- `main` -> Production Ready Code
- `develop` -> Integrations-Branch
- `feature/*` -> Einzelne Epic-Features
